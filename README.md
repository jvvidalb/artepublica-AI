# artepublica-AI

Image recognition built on a pretrained network: an ImageNet-pretrained network (ResNet-50,
MobileNetV2, EfficientNet-B0 or MobileNetV4) whose backbone is frozen, with a new classification head trained on this project's images.

## Setup

```bash
pip install -r requirements.txt
```

## Data

Photos of four public sculptures in Rio de Janeiro, imported from Google Drive and sorted by
hand into one folder per sculpture:

| Folder in `data/raw/` | Images |
| --- | --- |
| `escultura_para_o_rio` | 64 |
| `o_passante` | 37 |
| `retangulo_vazado` | 38 |
| `sem_titulo_amilcar_de_castro` | 31 |

`data/other/` holds files from the same Drive folder that are not used for training: newspaper
clippings, plaque photos, street views without a sculpture, a collage and cover artwork.
Exact duplicate files were dropped.

Everything is committed, so cloning the repository is enough to get the images. To fetch the
Drive folder again (it must be shared by public link, and the network must reach Drive):

```bash
python scripts/download_data.py "<drive-folder-link>" --out drive_download
```

The Drive folder is flat, so newly downloaded photos have to be moved into the right
`data/raw/<sculpture>/` folder by hand. To add a new sculpture, create a new folder.

## Train

```bash
python src/train.py --arch resnet50 --data data/raw --epochs 8
```

`--arch` picks the pretrained network:

| `--arch` | Network | Total parameters |
| --- | --- | --- |
| `resnet50` (default) | ResNet-50 | 23.5 M |
| `mobilenet_v2` | MobileNetV2 | 2.2 M |
| `efficientnet_b0` | EfficientNet-B0 | 4.0 M |
| `mobilenetv4` | MobileNetV4 conv-medium (from `timm`) | 8.4 M |

Training holds out 20% of each class
for validation and saves the best checkpoint, with the class names, to `models/<arch>.pt`
(not committed). The split depends only on `--seed`, so all networks are scored on the same
validation images.

## Recognize new images

```bash
python src/predict.py --checkpoint models/resnet50.pt path/to/image.jpg
```

Prints the top 3 classes with their confidence.

## Compare all networks on a GPU (Google Colab)

`notebooks/artepublica_colab.ipynb` runs the whole process on Colab: it loads the images,
trains all four networks over several random splits, and produces a summary table, learning
curves, confusion matrices and a gallery of misclassified photos.

1. Upload the notebook to Colab and select a GPU runtime (*Runtime → Change runtime type → T4 GPU*).
2. On GitHub, download this branch with *Code → Download ZIP* and drag the zip into Colab's
   *Files* panel. If the repository is public the notebook clones it by itself instead.
3. *Runtime → Run all*. The last cell downloads `artepublica_results.zip` (numbers and figures).

The notebook is generated by `python scripts/build_notebook.py`; edit that script, not the `.ipynb`.
